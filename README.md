# Web Development Practice

## 📌 About

This repository is dedicated to improving my frontend web development skills by building projects using only **HTML**, **CSS**, and **JavaScript**.

The goal is to strengthen my understanding of web fundamentals by writing code manually without relying on AI-generated code or templates.

---

## 🎯 Objectives

- Improve HTML structure and semantic markup.
- Practice responsive layouts with CSS.
- Learn modern CSS techniques such as Flexbox and Grid.
- Strengthen JavaScript fundamentals.
- Build projects from scratch.
- Develop problem-solving skills through coding practice.
- Write clean, readable, and maintainable code.
